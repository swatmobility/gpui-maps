FOUR that `web/build.sh` ships beside it in `dist/`, and FIVE more that
`font_fallback::STORY_FONTS` bundles directly into the native (desktop and
capture) binary for the story design system's card (spec §4.1, D5) and
that neither `build.sh` nor the iOS shell ever touches. All nine are under

All five Modified Versions above are Modified Versions in the OFL's sense.
The OFL permits that (clause 1) and requires the licence and these
copyright notices to travel with them (clause 2), which is what this file
is for and why `build.sh` fails the build when it or either of the
**shipped** fonts' copyright holder's name is absent. The two story-only
holders (Adobe's 2023 Source Sans 3 line and IBM's) are covered by this
same file for the same clause-2 reason, even though no automated build
check watches them -- `build.sh` only ever builds the browser bundle, and
the native build has nothing equivalent to assert against.
